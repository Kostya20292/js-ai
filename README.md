# Дневная выручка

Отчёт о дневной выручке: агрегирует операции из двух источников, пересчитывает суммы в базовую
валюту по актуальному курсу и показывает использованные курсы.

Все денежные суммы хранятся в минорных единицах (копейках/центах), а разбор десятичных значений и
конвертация выполняются на `BigInt`, поэтому округления с плавающей точкой не искажают итоги.

## Стек

- React 19 + React Compiler
- TypeScript
- Vite
- SCSS-модули

## Запуск

```bash
pnpm install
cp .env.example .env
pnpm dev
```

В `.env` нужно указать два ключа:

| Переменная                     | Назначение                        |
| ------------------------------ | --------------------------------- |
| `VITE_FINANCE_API_KEY`         | доступ к источникам операций      |
| `VITE_EXCHANGE_RATES_API_KEY`  | доступ к api.currencyfreaks.com   |

## Скрипты

- `pnpm dev` — дев-сервер с HMR
- `pnpm build` — проверка типов и продакшен-сборка
- `pnpm preview` — локальный просмотр собранного бандла
- `pnpm lint` — ESLint

## Структура

```
src/
├── api/          запросы к источникам и работа с курсами
├── components/   компоненты, у каждого свой SCSS-модуль
├── config/       константы и переменные окружения
├── hooks/        useDailyRevenue — загрузка отчёта и состояния UI
├── services/     сбор отчёта и расчёт выручки
├── styles/       глобальные стили, переменные и миксины
├── utils/        разбор сумм, форматирование, хелперы
└── types.ts      общие типы домена
```
