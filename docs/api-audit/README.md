# Отчёты аудита API

Сюда складывается PDF-отчёт skill `finance-api-audit`.

Имя файла: `YYYY-MM-DD-finance-api-audit.pdf`.

Отчёт для авторов API / backend — **на русском**. Других артефактов (md, json) не хранить.

Экран «Источники данных» в приложении читает последний такой PDF (через Vite-плагин).
Без PDF список источников на экране не показывается.
