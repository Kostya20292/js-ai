# Стиль кода

Описание соглашений, которые уже используются в репозитории. Новый код должен им следовать.

## TypeScript

- Функции и компоненты: `const name = () => { ... }`, именованный `export` (без default для компонентов/утилит).
- Ранние возвраты и явные `throw new Error(...)` при невалидных данных.
- Внешний ввод сначала `unknown`, затем type guards (`isRecord`, `Array.isArray`).
- Сообщения об ошибках конкретные: что пришло и что ожидалось.
- Пропсы описываются отдельным типом: `type ButtonProps = { ... }`.
- Колбэки с префиксом `handle`: `handleReload`, `handleRetry`.
- Булевы флаги — префикс `is` / `with` где уместно (`isBusy`, `withApiKey`).

## React

- Только функциональные компоненты.
- Состояния экрана — дискриминантный union (`ReportState`: `loading` | `error` | `success`).
- У каждого компонента папка `Name/Name.tsx` + `Name.module.scss`.
- Классы: SCSS Modules + `clsx` при условных классах.
- a11y: `aria-*`, `role="alert"` для ошибок, декоративные иконки с `aria-hidden`, `useId` для связей label/section.

## Проверки перед сдачей

```bash
pnpm lint
pnpm build
```

`build` включает проверку типов (`tsc -b`). Не отключай ESLint без необходимости. Не оставляй `TODO`, заглушки и мёртвый код.
